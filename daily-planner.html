Connect to Microsoft Outlook

To get two-way sync with your Outlook calendar, you need a free Microsoft Azure app ID. This is a one-time setup that takes about 10 minutes.

  1. Go to portal.azure.com and sign in with your Microsoft account
  2. Search for App registrations and click New registration
  3. Give it any name (e.g. "My Daily Planner"), leave defaults, click Register
  4. Copy the Application (client) ID shown on the overview page
  5. Go to Authentication → Add a platform → Single-page application
  6. Set redirect URI to:
  7. Under API permissions, add: Calendars.ReadWrite and Tasks.ReadWrite
  8. Paste your Client ID below and click Save

Your Client ID is stored only in this browser. It never leaves your device.
